# Сайт платного отделения РКБ «Сихат», https://rkb-sihat.ru/

## Задачи редизайна

1. Сделать сайт аккуратнее, красивее и современнее.
2. Сделать удобную форму записи на приём.
3. Добавить запись к врачу с расписанием.
4. Добавить оплату услуг (сейчас есть только для приёма врача).
5. Массовое обновление цен из файла xls (на дизайн почти не влияет).

## Референсы

Нравятся заказчику (совпадают не по всем услугам):

- https://milleniumclinic.ru/patients/
- https://www.k31.ru/

## Обязательные требования к сайтам медуслуг

- мультиязычность;
- версия для слабовидящих;
- полный прайс на услуги;
- данные специалистов;
- полное наименование, реквизиты и т.п.

## Разделы сайта

Главная; Каталог направлений услуг (страница направления, страница услуги); Каталог специалистов (страница специалиста); Цены; Пациентам; Контакты; Документы; О нас; Новости (страница новости).

## Вложенность услуг

Каталог направлений (`/napravleniya/`) → страница направления (`/napravleniya/chek-ap-programmy/`) → страница услуги.

## Страница каталога услуг

- рубрикатор;
- список услуг;
- приаттаченный полный прайс (можно поставить сверху).

## Страница направления

Ключевая страница, с неё идёт основной трафик заявок.

- описание направления;
- этапы получения услуг;
- список услуг со стоимостью и прейскурантом;
- специалисты;
- документы для пациентов;
- что взять с собой.

## Страница услуги

Во многом повторяет страницу направления.

- описание и стоимость;
- кнопка «Оплатить услугу»;
- этапы;
- врачи;
- документы;
- что взять;
- другие услуги из направления.

## Цены

Одна страница со списком цен.

- Аккордеон: направления, внутри услуги с ценами.
- Поиск по странице.
- В строке услуги: наименование, внутренний код, стоимость, при необходимости подтекст с описанием.

Атрибуты услуги: название; краткое описание; код услуги по номенклатуре медицинских услуг; цена.

## Главная

- главный экран с переходом на форму или звонок;
- приоритетные направления (роды, чек-апы, хирургия и т.д.);
- специалисты;
- форма обратной связи.

## Шапка

Лого; услуги; врачи; пациентам; контакты; мессенджеры.

## Этап 1 дизайна

Главная и страница направления.
