# Сайт платного отделения РКБ «Сихат», https://rkb-sihat.ru/

## Задачи редизайна

1. Сделать сайт аккуратнее, красивее и современнее.
2. Сделать удобную форму записи на приём.
3. Добавить запись к врачу с расписанием.
4. Добавить оплату услуг (сейчас есть только для приёма врача).
5. Массовое обновление цен из файла xls (на дизайн почти не влияет).

## Референсы

Нравятся заказчику (совпадают не по всем услугам):

- https://milleniumclinic.ru/patients/
- https://www.k31.ru/

## Обязательные требования к сайтам медуслуг

- мультиязычность;
- версия для слабовидящих;
- полный прайс на услуги;
- данные специалистов;
- полное наименование, реквизиты и т.п.

## Разделы сайта

Главная; Каталог направлений услуг (страница направления, страница услуги); Каталог специалистов (страница специалиста); Цены; Пациентам; Контакты; Документы; О нас; Новости (страница новости).

## Вложенность услуг

Каталог направлений (`/napravleniya/`) → страница направления (`/napravleniya/chek-ap-programmy/`) → страница услуги.

## Страница каталога услуг

- рубрикатор;
- список услуг;
- приаттаченный полный прайс (можно поставить сверху).

## Страница направления

Ключевая страница, с неё идёт основной трафик заявок.

- описание направления;
- этапы получения услуг;
- список услуг со стоимостью и прейскурантом;
- специалисты;
- документы для пациентов;
- что взять с собой.

## Страница услуги

Во многом повторяет страницу направления.

- описание и стоимость;
- кнопка «Оплатить услугу»;
- этапы;
- врачи;
- документы;
- что взять;
- другие услуги из направления.

## Цены

Одна страница со списком цен.

- Аккордеон: направления, внутри услуги с ценами.
- Поиск по странице.
- В строке услуги: наименование, внутренний код, стоимость, при необходимости подтекст с описанием.

Атрибуты услуги: название; краткое описание; код услуги по номенклатуре медицинских услуг; цена.

## Ответы заказчика, 02.11

Источник правды с этой даты. Где ответ расходится с текстом выше, действует ответ. Разбор: docs/review-client-answers-1.md.

1. **Айдентика.** У Сихата своя айдентика, не система РКБ 2.0. Она близка к текущему сайту https://rkb-sihat.ru/: сине-зелёная палитра и шрифт, похожий на их (квадратный, геометрический). Остальное не зафиксировано. Логотип берём из шапки текущего сайта.
2. **Референсы.** milleniumclinic.ru и k31.ru нравятся как аккуратные, хорошо структурированные и наполненные сайты популярных премиальных клиник Казани. Берём решения для целевых страниц (запись, категории услуг, прайс), а не айдентику.
3. **Расписание.** Слоты будут приходить из админки, расписание часто меняется. Сейчас его ведут вручную в другой системе.
4. **Запись: два сценария, оба затем подтверждает администратор.**
   - а) Запись на услугу без точного времени: заявка, администратор перезванивает и подтверждает.
   - б) Запись к врачу: выбор даты и времени, оплата по желанию, затем подтверждение администратора. Это полный сценарий.
5. **Оплата.** Возможна сразу при записи, по желанию, полная, только там, где цена фиксирована. Услуги часто покупают набором, поэтому пока оплата только за приём врача, не за отдельные услуги. Отменяет «кнопку „Оплатить услугу“» на странице услуги и задачу 4 в части оплаты услуг.
6. **Приоритетные направления на главной:** Чек-ап программы, Роды, Хирургия, в этом порядке.
7. **Врачи на главной:** первые врачи из общего каталога https://rkb-sihat.ru/doctor/ с настоящими фото с этого сайта. Какие именно, пока не важно.
