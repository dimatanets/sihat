# Сайт платного отделения РКБ «Сихат», https://rkb-sihat.ru/

## Задачи редизайна

1. Сделать сайт аккуратнее, красивее и современнее.
2. Сделать удобную форму записи на приём.
3. Добавить запись к врачу с расписанием.
4. Добавить оплату услуг (сейчас есть только для приёма врача).
5. Массовое обновление цен из файла xls (на дизайн почти не влияет).

## Ответы заказчика, 02.11

Источник правды с этой даты. Где ответ расходится с текстом выше, действует ответ. Разбор: docs/review-client-answers-1.md.

1. **Айдентика.** У Сихата своя айдентика, не система РКБ 2.0. Она близка к текущему сайту https://rkb-sihat.ru/: сине-зелёная палитра и шрифт, похожий на их (квадратный, геометрический). Остальное не зафиксировано. Логотип берём из шапки текущего сайта.
2. **Референсы.** milleniumclinic.ru и k31.ru нравятся как аккуратные, хорошо структурированные и наполненные сайты популярных премиальных клиник Казани. Берём решения для целевых страниц (запись, категории услуг, прайс), а не айдентику.
3. **Расписание.** Слоты будут приходить из админки, расписание часто меняется. Сейчас его ведут вручную в другой системе.
4. **Запись: два сценария, оба затем подтверждает администратор.**
   - а) Запись на услугу без точного времени: заявка, администратор перезванивает и подтверждает.
   - б) Запись к врачу: выбор даты и времени, оплата по желанию, затем подтверждение администратора. Это полный сценарий.
5. **Оплата.** Возможна сразу при записи, по желанию, полная, только там, где цена фиксирована. Услуги часто покупают набором, поэтому пока оплата только за приём врача, не за отдельные услуги. Отменяет «кнопку „Оплатить услугу“» на странице услуги и задачу 4 в части оплаты услуг.
6. **Приоритетные направления на главной:** Чек-ап программы, Роды, Хирургия, в этом порядке.
7. **Врачи на главной:** первые врачи из общего каталога https://rkb-sihat.ru/doctor/ с настоящими фото с этого сайта. Какие именно, пока не важно.


## Правки заказчика, 18.11.2026

Новое согласованное Димой задание имеет приоритет над прежним составом этапа 1. Изначально реализация велась только локально. После завершения правок 18.11.2026 Дима явно попросил обновить деплой; публикация текущей версии разрешена.

1. В шапке пункт «Прайс-лист»: отдельная страница услуг по категориям, поиск по названию и коду, пример структуры — k31.ru/price/. В макете используются доступные демонстрационные данные; полного прайса клиники нет.
2. В шапке и мобильном меню MAX и ВКонтакте, без Telegram и WhatsApp. Подвал не меняем.
3. Кнопка шапки «Записаться на приём» на всех ширинах, переход к форме.
4. Крупная асимметричная плитка: Чекапы; Беременность и роды; Анализы; Операции. Отдельные новые страницы направлений не входят в эту правку.
5. После направлений компактный баннер «Получить консультацию»: «Поможем выбрать специалиста», звонок или обратная связь в течение 5 минут; телефон, согласие, «Перезвоните мне».
6. В карточках врачей рейтинг и количество отзывов.
7. Одна закрываемая карточка акции снизу справа: −10% на чекап «Мужское здоровье». Реальные условия уточняет клиника.
8. Плитка «Пациентам»: налоговый вычет, будущим родителям, льготы, о клинике. Локальная страница с четырьмя разделами и кратким предварительным содержимым.
9. Слайдер отзывов с оценкой врача. Все вымышленные оценки, количества и отзывы явно обозначены как демонстрационные.
10. Повтор баннера консультации после отзывов.
11. Лицензии и сертификаты: документы и ссылки на доступные PDF. Недостающие документы отмечены до получения файлов, без вымышленных лицензий.
12. Контакты: обычная Яндекс Карта по нажатию и список корпусов/отделений. Автоматических внешних запросов со страницы нет; карта — исключение после действия пользователя.
13. Общая форма: убрать выбор направления, способ связи — кнопки с одиночным выбором, добавить необязательную электронную почту. Существующие варианты связи сохраняются. Отправка всех форм остаётся демонстрационной.

## Уточнения Димы, 18.11.2026

Эти указания имеют приоритет над предыдущими пояснениями о составе макета.

1. В основной навигации выбранный пункт выделен синим текстом и короткой линией снизу, как текущий язык. При наведении меняется только цвет текста на более тёмный.
2. Рейтинг врача: пять жёлтых заполненных звёзд, число и количество оценок, по присланному скриншоту. На отзыве рейтинг расположен у имени автора, без количества оценок.
3. Карточки пациентов белые, без стрелок. Иконка вверху, текст прижат к низу. При наведении синий фон и светлое содержимое.
4. Плитка анализов при наведении синяя, с белым текстом.
5. Карта — локальный скриншот Яндекс Карт высокого разрешения с собственным пином клиники, без интерактивной загрузки.
6. В списке отделений убрать квадраты с В/Д/А. Телефон и режим работы сгруппировать рядом.
7. В интерфейсе запрещены пояснения о макете, демонстрационных данных, недостающих файлах и будущем поведении. Нет файла или ссылки — элемент сохраняет обычный дизайн и не нажимается; без пометок и специальных состояний. Другие неоговорённые нюансы обсуждать с Димой в чате. Правило сохранено в AGENTS.md.
